One line, max 200 characters — a pickup line from a vending machine to a human.

> Are you a snack? Because I have been waiting all day just to drop everything for you, and I only take exact change.

Run `main.ts` with Node and it writes exactly that line (115 characters, no trailing newline) to `entry.txt` in the output directory.
